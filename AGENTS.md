# Agent Guide

## Project

Next.js, Fumadocs, React, and Tailwind documentation for the Peers ecosystem.

## Commands

- Install: `npm ci`
- Lint: `npm run lint`
- Typecheck: `npm run typecheck`
- Build: `npm run build`

## Conventions

- Keep source pages and MDX content separated.
- Preserve the existing docs information architecture and visual style.
- Do not claim security properties that the implementation does not provide.
- Update cross-links when routes change.
- Prefer short, operator-focused runbooks over marketing copy.

## Verification

Run `npm run lint`, `npm run typecheck`, and `npm run build` before committing.
